# Migrations

One migration guide per version, under that version's folder. The root of `docs/`
holds only what is true of the current version; each `vX.Y.Z/` folder holds that
version's documentation, frozen as it was shipped. See `docs/README.md` for the
folder rule.

| Upgrading to | Guide |
|---|---|
| 0.2.0 (from 0.1.0) | [v0.2.0/MIGRATION.md](v0.2.0/MIGRATION.md) |
| 0.3.0 (from 0.2.1) | [v0.3.0/MIGRATION.md](v0.3.0/MIGRATION.md) |

The version policy itself is [SEMVER.md](SEMVER.md); how a release is published is
[RELEASING.md](RELEASING.md).
