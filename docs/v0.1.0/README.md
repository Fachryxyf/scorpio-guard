# 0.1.0: the record

The first version published to npm, on 2026-08-24. Uploaded by hand, which is the whole
story of this folder: the tag `v0.1.0` was pushed two months later, and because the
upload predates the tag-triggered workflow, the registry holds **no provenance
attestation** for this tarball and cannot gain one. `npm audit signatures` reports
nothing for 0.1.0.

What it means for you:

- 0.1.0 stays installable (`npm install @fachryxyf/scorpio-guard@0.1.0`) and is the
  documented rollback target for the 0.2.0 upgrade. See
  [the 0.2.0 migration guide](../v0.2.0/MIGRATION.md#rollback).
- Its advice predates every correction recorded in the 0.2.0 CHANGELOG entry. Pin it
  only if you have a reason; otherwise the registry's newest tarball is the default.
- The publish history, the account suspension of 2026-10-25, and the runbook that
  replaced hand-uploads are in [docs/RELEASING.md](../RELEASING.md).
